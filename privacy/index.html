개인정보처리방침

앞마당은 시연용 프로토타입이에요. 필요한 것만 받고, 실명과 전화번호는 받지 않아요.

  • 실명·전화번호 없음닉네임과 동·호수만
  • AI 대화는 저장 안 함답을 만들 때만 Gemini로 전송
  • 서울 리전에 보관Supabase · 접근 규칙으로 보호

실명, 전화번호, 생년월일, 위치(GPS), 연락처는 받지 않아요.

2AI 도우미

  • 도우미에 입력한 글은 답을 만들기 위해 Google Gemini API로 보내요.
  • 대화 내용은 앞마당 서버에 저장하지 않아요. 앱을 닫으면 사라져요.
  • Google 쪽 처리는 Gemini API 약관을 따라요. 이름·전화번호 같은 개인정보는 입력하지 마세요.

3보관과 맡기는 곳

  • Supabase (서울 리전): 위 정보를 보관해요. 세대별 접근 규칙으로 다른 세대는 볼 수 없어요.
  • Google Gemini: AI 도우미 답 생성 (저장 안 함).
  • Expo 푸시 서비스: 알림 전달.
  • GitHub Pages: 이 웹페이지와 설치 파일 배포.
